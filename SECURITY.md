# Security

Security fixes are provided for the latest release. Please update before reporting an issue.

To report a security vulnerability privately, use [Report a vulnerability](https://github.com/vitosans/mac-middle/security/advisories/new). Include the app version, macOS version, impact, and steps to reproduce. Please keep sensitive details out of public issues.

Mac Middle requires Accessibility permission to control windows and listens for middle-button mouse events. Release downloads are ad-hoc signed and are not notarized by Apple.
